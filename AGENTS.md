1. **Start:** Read `HANDOFF.md` before exploring or writing code.
2. **End / File Callout:** Overwrite `HANDOFF.md` (`<20 lines`: exact file paths, build/test status, numbered next steps—no persona fluff) before finishing, opening a PR, or when asked `"viết hướng dẫn cho llm"`, `"viết md hướng dẫn"`, or `"tạo file hướng dẫn AI"` (also echo the `<20-line` block in chat).
3. **Sheet/Excel Export (EN/VI):** When asked for `"handoff for sheet"`, `"cho tôi hướng dẫn gg sheet cho AI"`, `"bàn giao cho sheet"`, or `"bàn giao qua Excel"`, output a standalone `<20-line` Markdown block in chat (matching user language, EN/VI) with Goal, Schema/Rules, and Next Steps to paste into `HANDOFF!A1` in Google Sheets or Excel.
