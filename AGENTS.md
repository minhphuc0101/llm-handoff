# Multi-Agent Handoff Protocol
1. **Start:** Read `HANDOFF.md` before exploring or writing code.
2. **End:** Overwrite `HANDOFF.md` before finishing or opening a PR. Keep under 20 lines: exact file paths, build/test status, and numbered next steps—no fluff.
3. **Sheet Export:** When asked for `"handoff for sheet"`, output a self-contained `<20-line` Markdown block in chat summarizing the project goal, current logic/schema, and exact next steps so a teammate can paste it into a Google Sheet for Gemini to read.
