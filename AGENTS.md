# Multi-Agent Handoff Protocol
1. **Start:** Read `HANDOFF.md` before exploring or writing code.
2. **End / Guide (`viết hướng dẫn cho llm` | `viết md hướng dẫn` | `tạo file hướng dẫn AI`):** Overwrite `HANDOFF.md` (`<20 lines`: goal, constraints, paths, status, next steps—no fluff) at wrap-up/PR or callout (& echo).
3. **Sheet/Excel (`handoff for sheet` | `cho tôi hướng dẫn gg sheet cho AI`):** Output `<20 lines` (EN/VI) for `HANDOFF!A1`—Goal, Constraints, Next Steps; if **reporting**, state **time range, update frequency**, **lineage** (`Sheet/Block <- Source via Method`).
4. **Slides/PPTX (`handoff for slides` | `cho tôi hướng dẫn slide cho AI`):** Output concise block (EN/VI, scales with slide count—no `<20-line` cap) for Slide 1 Notes / hidden `HANDOFF` slide—Goal/Audience, what to add per slide + **media/screenshots, charts, tables** (sources), Next Steps.
