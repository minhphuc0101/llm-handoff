# Multi-Agent Handoff Protocol
1. **Start:** Read `HANDOFF.md` before exploring or writing code.
2. **End:** Overwrite `HANDOFF.md` before finishing or opening a PR. Keep under 20 lines: exact file paths, build/test status, and numbered next steps—no fluff.
3. **Sheet/Excel Export (EN/VI):** When asked for `"handoff for sheet"`, `"bàn giao cho sheet"`, or `"bàn giao qua Excel"`, output a self-contained `<20-line` Markdown block in chat (matching the user's language, EN or VI) summarizing project goal, current logic/schema, and exact next steps to paste into `HANDOFF!A1` in Google Sheets or Excel.
