# Multi-Agent Handoff Protocol
1. **Start:** Read `HANDOFF.md` before exploring or writing code.
2. **End / File Callout:** Overwrite `HANDOFF.md` (`<20 lines`: exact paths, build/test status, numbered next steps—no persona fluff) before finishing, opening a PR, or on `"viết hướng dẫn cho llm"`, `"viết md hướng dẫn"`, `"tạo file hướng dẫn AI"` (echo block in chat).
3. **Sheet / Excel Export:** On `"handoff for sheet"`, `"cho tôi hướng dẫn gg sheet cho AI"`, `"bàn giao cho sheet"`, or `"bàn giao qua Excel"`, output a `<20-line` Markdown block (EN/VI) with Goal, Schema/Rules, and Next Steps for `HANDOFF!A1`.
4. **Slides / PPTX Export:** On `"handoff for slides"`, `"handoff for presentation"`, `"cho tôi hướng dẫn slide cho AI"`, or `"bàn giao cho slide"`, output a `<20-line` Markdown block (EN/VI) with Goal/Audience, Verified Metrics & Slide Map, and Next Steps for a hidden `HANDOFF` slide or Slide 1 Speaker Notes.
